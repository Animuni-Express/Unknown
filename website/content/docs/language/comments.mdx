Comments are ignored by the interpreter and help explain non-obvious decisions.

## Syntax

`//` starts a comment until the next newline. `/*` starts a block comment, which ends at `*/` and may span lines.

## Common mistakes

`#` is not a comment marker in Unknown. An unclosed block comment reports E0007. Keep indentation consistent around comments in indentation-based blocks.
