Functions group statements and optionally return a value. Calls evaluate arguments and check their count and any declared types.

## Syntax

Use `fn name(type argument) -> type` followed by a brace or indentation block. Parameter annotations and the return annotation can be omitted. `return expression` exits the current function. A function without a returned value produces `none`.

## Common mistakes

Wrong argument counts or incompatible annotated types report E2002. `return` outside a function reports E2003. Functions can see their own locals and globals; they do not capture enclosing function locals. See [scope](/docs/language/scope/).
