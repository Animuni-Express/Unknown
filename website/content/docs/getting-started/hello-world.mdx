`print` writes values to standard output. Multiple arguments are separated by a space; each call ends with a newline.

## Syntax

Call a function with parentheses. Wrap text in matching single or double quotes. Statements end at a newline; semicolons are not supported.

## Common mistakes

A missing quote causes an unterminated-string diagnostic. `Print` and `print` are different names. Copy the original diagnostic or select **Go to error** to inspect its position.
